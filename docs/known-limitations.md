# 알려진 한계

## 데이터 구조

- results_long은 표 구조를 대학별 헤더 그대로 평탄화한 long 포맷이라, 수능위주(40)는 대학마다 지표 조합이 다릅니다.
- criteria_text는 대학 서술형 원문을 섹션 단위 텍스트로 보존한 것이며 완전 구조화가 아닙니다.

## 데이터 품질

- 일부 대학(가야대, 감리교신학대 등)은 결과를 이미지로만 공개해 이미지로 저장됩니다.
- 강남대는 웹페이지를 PDF 인쇄본으로 보관합니다.
- 중복 캠퍼스(건양 제2, 경기 제2, 경동 제3·제4 등)는 본교 사이트를 공유해 동일 자료가 복제되어 있습니다.

## 정규화

- AI 정규화(11_run_agent.py)는 근거 위치(locator)와 인용(quote) 일치를 검증하지만, 원문의 표 구조 오독 가능성은 남아 있습니다.
- 전형 분류(classify_selection.py)는 전형명과 정규화된 전형 단계를 기반으로 하므로, 문서에 근거가 없는 경우 기타로 분류됩니다.
